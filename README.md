# Exploratory Data Analysis of Student Performance

## Project Overview

This project explores student performance data using Python, Pandas, Matplotlib, and Seaborn. The objective is to identify patterns, compare exam scores, and investigate relationships between student characteristics and academic performance.

## Objectives

* Explore the structure and characteristics of the dataset.
* Check for missing values and duplicate records.
* Calculate descriptive statistics.
* Visualize score distributions and group differences.
* Analyze correlations between mathematics, reading, and writing scores.
* Investigate differences associated with test preparation.

## Dataset

The dataset contains 1,000 student records and eight columns, including gender, parental education, lunch type, test preparation course, and mathematics, reading, and writing scores.

## Tools and Technologies

* Python
* Jupyter Notebook
* Pandas
* NumPy
* Matplotlib
* Seaborn

## Analysis Performed

1. Dataset inspection and data cleaning.
2. Statistical summaries of exam scores.
3. Mathematics score distribution analysis.
4. Mathematics score comparison by gender.
5. Average score comparison by test preparation course.
6. Correlation analysis between exam subjects.

## Key Findings

The notebook calculates average exam scores, compares student groups, and measures correlations between subjects. The specific numerical findings should be taken from the notebook's analysis output.

## Conclusion

This project demonstrates how exploratory data analysis can help identify patterns and relationships in student performance data. The results describe associations in the dataset and do not establish that any particular factor causes higher exam scores.

5. Run the notebook cells in order.
